# Plan an Adobe Content Analytics implementation

Learn how the ACA Implementation Guide in CX Enterprise Coworker creates a tailored Adobe Content Analytics implementation plan, whether you're adding Content Analytics to an existing Customer Journey Analytics (CJA) deployment or starting with a standalone setup.

## What you'll learn

- How Coworker uses a guided discovery process to capture licensing, channels, SDKs, behavioral data, identity stitching, privacy, and reporting requirements.
- How the guide sequences implementation phases, assigns owners, identifies dependencies, and estimates a critical-path timeline.
- How plans differ between an existing CJA deployment and a standalone Content Analytics implementation.
- How to track progress, revise assumptions, and export implementation tasks to CSV and Jira.

>[!VIDEO](https://video.tv.adobe.com/v/3508620/?learn=on&enablevpops)

## Add Content Analytics to an existing CJA deployment

The first walkthrough starts with an organization already using CJA across web and mobile. Adobe Tags and Web SDK support the website, Mobile SDK supports the apps, and the CJA connection, data views, and datastream already exist.

Based on the answers, Coworker produces a plan that accounts for all the tasks required for a successful implementation and dependencies outside the implementation team's control.

## Start with standalone Content Analytics

The second walkthrough begins with no existing CJA deployment. 

Coworker generates a plan that includes confirming behavioral data requirements with the Adobe account team and creating the schema and dataset for web behavioral data. The guided wizard creates the CJA connection and data view. 

## Track progress and export the plan

The video demonstrates an interactive one-page tracker where steps can be marked complete, reopened, or deferred. Coworker can update the plan when implementation details change and regenerate its files. 

The guide supports other export formats, including:

- **CSV:** Implementation steps with phase, effort, owner, dependencies, and status.
- **Jira:** A backlog-ready structure with phases as epics and steps as stories, including priority and story points.

## Key takeaway

The ACA Implementation Guide in Adobe Coworker turns implementation requirements into a sequenced, actionable plan. By adapting to your starting environment and surfacing security, privacy, and configuration dependencies early, it helps teams coordinate and track an Adobe Content Analytics rollout.
