# Create and refine an AEM landing page with Coworker

Learn how to turn a campaign brief into a draft landing page with Adobe CX Enterprise Coworker. Follow the workflow to use an existing Adobe Experience Manager page as a template, confirm the destination, apply campaign content and SEO metadata, and refine imagery and copy in the Universal Editor.
